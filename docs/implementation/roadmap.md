# Implementation Roadmap

Phase 1 prioritizes the durable foundation:

1. Repository and specification foundation
2. NixOS bootable, installable and recoverable ISO
3. PostgreSQL schema and durable event queue
4. Agent Core state machine
5. Resource Controller
6. Recovery Manager
7. Workspace Runner
8. Inference adapters and admission control
9. Repository Intelligence
10. Optional Research Engine
11. Optional Skill Engine

Canonical task dependencies and acceptance evidence are in [tasks.md](tasks.md).
