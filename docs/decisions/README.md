# Architecture Decisions

Locked decisions are canonical in [design.md](../architecture/design.md).

| Decision range | Area |
|---|---|
| D-001–D-024 | Baseline NixOS, agent, inference, security and recoverability decisions |
| D-025–D-028 | Offline and recovery governance, plus the latest recovery lock |
| D-025–D-028 | Orchestration-first architecture, Agent Core center, offline survivability and recovery |
| D-029–D-031 | Logical module boundaries and repository/task contracts |

Material proposed changes must include:

- date and rationale;
- alternatives considered;
- implementation impact;
- migration notes;
- owner approval before changing a locked decision.
